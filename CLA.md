## How you sign

When you open your first pull request, a bot asks you to sign. You sign by posting this comment
in the pull request, from the GitHub account that made the contribution:

```text
I have read the CLA Document and I hereby sign the CLA
```

You sign once; later pull requests do not ask again. The record of the signature is your GitHub
account name and number, the pull request and comment it came from, the date and the version of
this agreement. Nothing else about you is collected.
