## Runtime And Build Dependencies

Dosplex depends on operating-system packages and libraries that are not bundled as Dosplex source code in this repository. Users and distributors must comply with those projects' licenses when installing, linking, packaging, or redistributing them.

Known dependencies referenced by the build and SteamOS packaging include:

- wlroots / wlroots0.17 / wlroots-0.18
- Wayland server/client libraries
- wayland-protocols
- xkbcommon
- cairo
- json-c (MIT/Expat; dynamically linked session-state JSON parser)
- libfuse3 (LGPL-2.1; used by the native controller relay helper)
- PAM
- libinput
- systemd
- udev
- PipeWire / PulseAudio-compatible audio services
- Gamescope
- Steam / SteamOS components
- Input Leap / Barrier protocol compatibility components
- Python and Python modules used by helper daemons, including evdev where installed
- QML/KDE/Qt components used by Deck helper overlays

These components are not licensed by the Dosplex license. Their licenses should be checked at packaging or release time against the exact versions distributed or required.

A binary release bundles wlroots 0.17, libdisplay-info and libliftoff (all three MIT) as shared libraries, with their license texts. Data of the hwdata package is compiled into wlroots and libdisplay-info; its license is recorded in the generated notices of the release. The other libraries above are provided by the host system, and the generated notices list them as such.

The native controller relay helper uses libfuse3, which is licensed under the GNU Lesser General Public License, version 2.1 (LGPL-2.1). A binary release must link it dynamically against the system's `libfuse3.so.3`, or ship it as a separate shared library, so that a user can replace it with a modified version; it must not link it statically without a way to relink. The generated notices of a release that contains the helper carry the LGPL-2.1 statement for libfuse.

## Other Assets

No screenshots of games, fonts, icons or other third-party images are bundled. The overlay text uses the system's default sans-serif font through cairo.

If additional images, icons, fonts, generated protocol files, vendored libraries, or copied snippets are added later, list them here with origin, license, and any attribution text required by the upstream license.

## Provenance

The controller report layouts that Dosplex reads (the byte offsets and bit masks of the HID reports of the supported controllers) were derived from public Linux kernel documentation. No code was copied from the kernel sources.
