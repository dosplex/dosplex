# Start and sign in

## Start DosPlex

1. Open **DosPlex** under **Non-Steam** in Steam's library.
2. Press **Play**.
3. Wait. Steam closes, and after about half a minute both sides are there.

> [!NOTE]
> The first start after an install takes longer. Guest's half can stay black for a few minutes.

- Only Main's account can start DosPlex this way.
- Nothing runs before you press **Play**.
- No entry in the library? See [Install](03-install.md).
- Or use the DosPlex icon on the desktop, or run `sudo /opt/dosplex/bin/dosplex start` in Desktop mode. It takes up to two minutes.

## Sign in

Each half runs its own Steam. Sign in on your half with Steam's normal screen, including QR code and Steam Guard. Guest signs in on theirs. Guest may stay signed out.

| You want to | Do this |
|---|---|
| Give the second player a controller | Wake a second controller. It goes to them while they have none. |
| Sign in with no controller | Scan the QR code on Steam's sign-in page with the Steam mobile app. |
| Move a controller by hand | Main does the steps below. |

1. Open the DosPlex menu.
2. Choose **Devices** and pick the controller.
3. Choose **Guest**.
4. Choose **Keep assignment**.

A mouse or keyboard is Main's until Main hands it over. To use a Steam Controller on the second side, pair and assign it before sign-in.

More: [the user guide](../user-guide.md#start-and-sign-in).
